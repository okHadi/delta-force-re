# Type slot mark

`mission_type_mark` runs44A3E0. Pass the source scalar index from the behavior action's first argument. It shifts that value left6 bits with32-bit wrapping, adds7936A4, and stores the four-byte value2.

Use `mission_type_count_bindings(state,types)` to write the current `AiTypeSlotTable`. Reached addresses outside that table report a missing owner. Sparse address providers can test the raw wrapping body.

Validation:328 original cases each with the normal and ASAN/UBSAN/no-elision probe, zero differences. Native checks use the current type-table writer. Windows compilation passes for the module, probe and native test.
